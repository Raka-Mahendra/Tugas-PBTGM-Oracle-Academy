2. Rumus untuk mengonversi galon ke liter adalah: 1 galon AS = 3,785 liter. Program ini akan mengonversi jumlah galon tertentu (10) ke liter dan kemudian menampilkan outputnya. Konsep-konsep dalam latihan ini akan dieksplorasi lebih lanjut sepanjang kursus. Buat sebuah project, package, dan class Java baru dengan sebuah main method. Gunakan kode di bawah ini sebagai titik awal dan lengkapi kode untuk program tersebut. (Beri nama package Anda galToLit dan class GalToLit). 

```
package galToLit;
public class GalToLit {
    public static void main(String[] args) {
        // declare variables
        double gallons=10;
        double liters=0;
        // add your calculation here
        //output the result to user
        System.out.println(gallons+" gallons equals "+liters+" liters");
    }
}
```
