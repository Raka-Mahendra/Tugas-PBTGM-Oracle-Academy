6. Seorang profesor di perguruan tinggi akan membebaskan mahasiswa dari ujian akhir jika salah satu dari hal berikut terpenuhi: 

   - a. Memiliki rata-rata nilai 90% atau lebih tinggi di kelas dan telah absen 3 kali atau kurang. 

   - b. Memiliki rata-rata nilai 80% atau lebih tinggi di kelas dan tidak pernah absen sama sekali. 

   - c. Program di bawah ini akan menentukan apakah seorang mahasiswa dapat dibebaskan dari ujian atau tidak. 

   - d. Tulis ulang program agar hanya menggunakan satu pernyataan if. 

```
import java.util.Scanner; 

public class FinalExam{ 

    public static void main(String[] args) 
    { 
        double average; 
        int daysAbsent; 
        boolean exempt=false; 
        Scanner reader= new Scanner(System.in); 

        System.out.println("This program will determine if you can get out of the final exam."); 
        System.out.println("Please answer the following questions."); 
        System.out.println("What is your average in the class?"); 
        average=reader.nextDouble(); 
        System.out.println("How class lectures have you missed?"); 
        daysAbsent=reader.nextInt(); 

        if(average>=90) 
        { 
            if(daysAbsent<=3) 
                exempt=true; 
        } 
        else if(average>=80) 
        { 
            if(daysAbsent<=0) 
                exempt=true; 
        } 

        if(exempt) 
            System.out.println("Congratulations! You are exempt from the final exam."); 
        else 
            System.out.println("You are not exempt from the final exam."); 

    }//end of main 
}//end of class 
```
