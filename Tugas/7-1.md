2. Identifikasi bagian-bagian kunci dari class Java di bawah ini. Berikan tanda bintang pada semua instance variable. Gambarkan kotak di sekitar setiap constructor. Lingkari signature dari method-method selain constructor. Berikan tanda segitiga di sekitar parameter. Garis bawahi tipe kembalian (return type) dari method-method. 

```
public class Animal { 
    int weight, height; 
    double speed; 
    Animal() { 
        weight = 50; 
        height = 4; 
        speed = 2; //miles per hour 
    } 
    Animal(int w, int h, int s ) { 
        weight = w; 
        h = height; 
        speed = s 
    } 
    public double getTime(double miles) { //mendapatkan jumlah jam untuk menempuh jarak ini 
        return miles/speed; 
    } 
    public int getWeight() { return weight; } 
    public int getHeight() { return height; } 
    public double getSpeed() { return speed; } 
} 
```
