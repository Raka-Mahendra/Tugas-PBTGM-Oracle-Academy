# **Java Fundamentals** 

## **4-4: String Aktivitas Latihan** 

### **Tujuan Pembelajaran:** 

- Menginstansiasi (membuat) sebuah String 

- Mendeskripsikan apa yang terjadi ketika sebuah String dimodifikasi 

- Menggunakan operator + dan += untuk konkatenasi String 

- Menginterpretasikan escape sequence dalam literal String 

- Mengenali perbedaan antara String dan tipe data primitif char 

- Menguji String dengan method compareTo() dan equals() 

- Menjelaskan mengapa operator == tidak selalu berfungsi saat menguji kesamaan String 

- Menggunakan method-method String: length(), substring(), indexOf(), dan charAt()
